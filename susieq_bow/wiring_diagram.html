Do You Need External Resistors?

No Resistors Needed

TF-Luna LiDAR (UART)

Direct UART connection — no pull-up or pull-down resistors required. The TF-Luna operates at 3.3V logic which matches the ESP32 natively. Just connect TX→RX, RX→TX, 5V, and GND.

No Resistors Needed

OV2640 Camera (SCCB / I²C)

The ESP32's internal pull-up resistors handle the SCCB (I²C) bus for camera configuration on GPIO 26/27. The camera module is mounted directly on the ESP32-CAM board — all connections are internal.

Current design: no external resistors required.
Both the TF-Luna (UART) and OV2640 (on-board) work without any additional passive components. The only external wiring needed is 4 wires between the TF-Luna and the ESP32-CAM.

If you add sensors later…

Would Need Resistors

DS18B20 Temperature (OneWire)

Requires a 4.7 kΩ pull-up resistor between the data line and 3.3V. This is mandatory for the OneWire protocol to work reliably.

Would Need Resistors

I²C Sensors (BME280, etc.)

External I²C sensors typically need 4.7 kΩ pull-up resistors on SDA and SCL lines if you wire them on a separate I²C bus (not using the camera SCCB pins).

Level Shifter Recommended

5V Sensors / Devices

Any 5V logic device needs a logic level shifter (3.3V ↔ 5V) to protect ESP32 GPIO pins. The TF-Luna already operates at 3.3V logic, so it's fine as-is.
